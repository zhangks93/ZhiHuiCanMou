# Phase 3 实施方案选项

## 当前状态

✅ **Phase 1 完成**: Agent 核心架构（TypeScript）
✅ **Phase 2 完成**: Business Analysis Skill（总览、对比、下钻）

## Phase 3 可选方向

### 选项 A: 扩展 Skill 能力（推荐）

**目标**: 增加更多实用的 Skill，提升 Agent 的能力范围

#### A1. Web Search Skill
**功能**: 联网搜索能力，获取实时信息

**实现方案**:
- 使用 Tavily API（需要在设置页面配置 API Key）
- 或使用 DuckDuckGo 免费搜索
- 返回搜索结果摘要和来源链接

**使用场景**:
```
用户: "搜索一下教育后勤行业的最新政策"
Agent: [调用 web_search skill]
Agent: "根据搜索结果，最近的政策包括..."
```

**工作量**: 1-2 天
**优先级**: 中

#### A2. Report Generation Skill
**功能**: 生成 PDF/Excel 报告

**实现方案**:
- 使用 jsPDF 生成 PDF（客户端）
- 使用 xlsx 库生成 Excel
- 包含图表、表格、分析文本
- 保存到本地文件系统

**使用场景**:
```
用户: "生成一份2026年3月的经营分析报告"
Agent: [调用 business_analysis + report_generation]
Agent: "报告已生成，点击下载"
```

**工作量**: 2-3 天
**优先级**: 高

#### A3. Data Export Skill
**功能**: 导出查询结果为 CSV/Excel

**实现方案**:
- 将 Supabase 查询结果导出
- 支持自定义筛选条件
- 包含元数据（导出时间、筛选条件）

**使用场景**:
```
用户: "导出餐饮中心2026年3月的所有数据"
Agent: [调用 data_export skill]
Agent: "数据已导出，共 156 行"
```

**工作量**: 1-2 天
**优先级**: 中

#### A4. Trend Analysis Enhancement
**功能**: 增强趋势分析能力（多期间对比）

**实现方案**:
- 扩展 BusinessAnalysisSkill
- 支持多期间查询（如 202601-202603）
- 生成趋势图表（折线图、柱状图）
- 计算环比、同比增长

**使用场景**:
```
用户: "分析2026年1-3月的营收趋势"
Agent: [调用 business_analysis with trend query]
Agent: "营收呈上升趋势，环比增长..."
```

**工作量**: 2-3 天
**优先级**: 高

### 选项 B: 优化现有功能

**目标**: 提升用户体验和系统稳定性

#### B1. 改进 Skill 检测准确率
**问题**: LLM 有时无法准确判断是否需要调用 Skill

**解决方案**:
- 优化 Skill 检测 prompt
- 添加示例（few-shot learning）
- 实现 fallback 机制（如果检测失败，提示用户）

**工作量**: 1 天
**优先级**: 高

#### B2. 增强可视化效果
**改进点**:
- 添加图表库（如 recharts 或 chart.js）
- 实现柱状图、折线图、饼图
- 支持交互式图表（hover、zoom）
- 响应式设计优化

**工作量**: 2-3 天
**优先级**: 中

#### B3. 优化对话体验
**改进点**:
- 添加打字机效果（逐字显示）
- 支持消息编辑和重新发送
- 添加快捷问题按钮（Quick Actions）
- 支持语音输入（可选）
- 添加对话导出功能

**工作量**: 2-3 天
**优先级**: 中

#### B4. 性能优化
**改进点**:
- 实现请求缓存（相同查询不重复调用）
- 优化数据聚合算法
- 实现虚拟滚动（长对话列表）
- 减少不必要的重渲染

**工作量**: 1-2 天
**优先级**: 低

### 选项 C: 高级功能

**目标**: 实现更智能的分析能力

#### C1. 自动洞察生成
**功能**: Agent 主动发现数据异常和趋势

**实现方案**:
- 定期分析经营数据
- 识别异常值（如达成率突然下降）
- 生成洞察报告
- 推送通知给用户

**使用场景**:
```
Agent: "🔔 发现异常：餐饮中心本月营收达成率下降15%，建议关注"
```

**工作量**: 3-4 天
**优先级**: 低（需要先完成基础功能）

#### C2. 自然语言查询增强
**功能**: 支持更自然的查询方式

**改进点**:
- 支持 "3月" → "202603" 自动转换
- 支持模糊匹配节点名称
- 支持相对时间（"上个月"、"本季度"）
- 支持复杂查询（"对比餐饮和物业的利润率"）

**工作量**: 2-3 天
**优先级**: 中

#### C3. 多模态支持
**功能**: 支持图片、文件上传

**实现方案**:
- 支持上传 Excel 文件进行分析
- 支持上传图片（如报表截图）进行 OCR
- 使用 GPT-4 Vision 或 Claude 3 分析图片

**工作量**: 3-4 天
**优先级**: 低

### 选项 D: Rust 后端迁移（Zeroclaw）

**目标**: 将 Agent 迁移到 Rust 后端，提升性能

**优势**:
- 更好的性能（特别是数据聚合）
- 更低的内存占用
- 更安全的执行环境

**劣势**:
- 开发周期长（需要重写大部分逻辑）
- 调试复杂度增加
- 团队需要 Rust 技能

**工作量**: 5-7 天
**优先级**: 低（当前 TypeScript 方案已足够）
