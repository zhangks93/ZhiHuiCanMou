# 经营分析执行清单

仅用于经营分析、对比、诊断、异常扫描和报告。轻量查数直接按 `metrics.md` 查询。

## 1. 边界确认
- [ ] 已明确对象、期间、目的；完整报告缺对象时可默认集团整体，缺期间必须追问。
- [ ] scope 不清或已变更时，已调用 `resolve_org_nodes`。
- [ ] 多候选节点已让用户确认，并在后续查询中使用 `org_scope_key`。

## 2. 查询执行
- [ ] 查询前已读取 `metrics.md`。
- [ ] 普通分析默认覆盖学年预算与突围考核、当月 / 上月 / 截至当月累计。
- [ ] 完整报告已优先调用 `query_business_report_pack`，未用零散查数替代。
- [ ] 无依赖查询已尽量并行；相同参数结果已复用。

## 3. 数据检查
- [ ] 空结果已排查节点、期间、口径、指标。
- [ ] 达成率、差额、同比和判断均绑定明确期间口径。
- [ ] 已优先使用返回的 `actual`、`target_value`、`completion_rate`、`diff`、`yoy`。
- [ ] 数据缺失或矛盾时已降低结论强度。

## 4. 输出检查
- [ ] 输出包含经营含义，不只复述数字。
- [ ] 完整报告已使用 `writing_brief`、`section_briefs`、`evidence_ledger` 和 `quality_contract`。
- [ ] 完整报告终稿前已调用 `audit_business_report`，并修复 error 级问题。
- [ ] 图表配置仅在用户明确要求时输出。
- [ ] 结尾给出 1-3 个强相关下一步动作。
