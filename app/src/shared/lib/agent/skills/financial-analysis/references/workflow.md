# 经营分析执行清单

用于经营分析、横向比较、纵向趋势、诊断和异常扫描。轻量查数直接按 `metrics.md` 查询。

## 1. 边界确认
- [ ] 已明确对象、期间或默认期间、分析目的。
- [ ] scope 不清、用户切换对象或当前 scope 置信度不足时，已调用 `resolve_org_nodes`。
- [ ] 多候选组织已让用户确认，并在后续查询中使用 `org_scope_key`。
- [ ] 用户未指定期间时，已使用 Runtime Data Context 的最新月度期间，并说明实际 period。

## 2. 通用分析查询
- [ ] 查询前已读取 `metrics.md`。
- [ ] 普通经营分析默认不传 `metric_categories`，覆盖全部可用指标。
- [ ] 默认同时覆盖学年预算与突围考核；经营判断优先看突围考核，学年预算同步参照。
- [ ] 当前月数据已查询；需要目标风险或累计进度时已补查累计口径。
- [ ] 横向比较已查询目标上级子树或整棵树，并筛出同级 / 同类型组织节点。
- [ ] 纵向趋势已使用最近 6 个合法月度期间；不足 6 个时按可用期间说明。
- [ ] 相同参数结果已复用，未重复调用同一查询。

## 3. 数据检查
- [ ] 空结果已排查组织范围、期间、口径、指标。
- [ ] 横向比较对象与目标节点层级、类型或业务属性一致。
- [ ] 达成率、差额、同比和判断均绑定明确期间口径。
- [ ] 已优先使用返回的 `actual`、`target_value`、`completion_rate`、`diff`、`yoy`。
- [ ] 数据缺失或矛盾时已降低结论强度。

## 4. 输出检查
- [ ] 输出包含经营含义，不只复述数字。
- [ ] 结构包含本次使用数据、核心结论、横向比较、纵向趋势、指标诊断、风险原因和建议动作。
- [ ] 每个关键判断有实际值、目标值、达成率、差额、同比或环比支撑。
- [ ] 建议具体到规模恢复、毛利修复、成本控制、费用纪律、人效优化、目标跟踪或重点单位干预。
- [ ] 结尾给出 1-3 个强相关下一步动作。

## 5. 输出边界
- [ ] 用户要求报告、月报、汇报材料或 markdown 报告时，已按通用经营分析结构输出可复用内容，而不是进入完整报告生成流程。
- [ ] 未调用或提及已移除的完整报告工具。
- [ ] 图表配置仅在用户明确要求时输出。
