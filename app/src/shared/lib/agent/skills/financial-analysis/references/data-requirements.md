# 数据覆盖与人工补充边界

## 可自动生成

来自系统经营数据和组织层级数据：
- 收入、毛利、税前利润、利润率、人力成本及明细、部分费用、人效指标。
- 学年预算、突围考核、目标值、完成率、差额、同比。
- 组织层级树、组织范围键、提问组织下属两层经营明细。
- 当月、上月、截至当月累计、学年目标累计。
- 报告包中的写作素材、宽表、排行、风险、质量契约和证据台账。

## 必须人工补充

当前系统不可自动取得：
- 应收账款、回款、账龄。
- 资金计划、实际收支、现金净流量、奖惩测算。
- 核心费用专项明细，如办公用品费、咨询 / 维修 / 服务费。
- 合同 / 在手订单、项目进度、全年预测、责任人和完成时点。

## 处理规则

- 自动可取的章节必须尽量完整，不得因专项数据缺失而省略核心经营分析。
- 自动可取的人力成本、物资成本、车辆费用、能耗费、差旅费、招待费等指标不得写成待补。
- 人工补充内容不得编造，只能放在“数据限制与待补说明”。
- 累计数据必须区分“截至当月累计”和“学年目标累计”。
- 当月实际值在学年预算与突围考核口径一致时可合并展示；累计实际值必须按两个统计口径分别展示和解释，不能共用一个实际值。
- 完整报告必须至少下钻两层组织描述；有二级下属时必须写出第二层节点名称和具体数字。
