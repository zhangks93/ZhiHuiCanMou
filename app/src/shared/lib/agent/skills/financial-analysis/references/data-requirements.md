# 经营分析报告数据覆盖说明

## 系统当前可自动生成

来自 `edu_biz_report`、`edu_biz_monthly_plan`、`edu_org_hierarchy`：
- 营业收入
- 毛利额、毛利率
- 税前利润、税前利润率
- 人力成本及部分明细
- 部分费用类指标
- 人数、人均营收、人力成本率、一元创收、一元创利
- 年初预算目标、突围考核目标
- 完成率、差额、同比值
- 组织层级树
- 突围月度计划中的 revenue、pretax_profit
- 完整报告包中的 `writing_brief`、`cost_expense_summary`、`cost_expense_table`、`variance_rankings` 成本费用排行数据

## 当前必须人工补充

以下数据目前业务侧取不到，报告只能在结尾说明补数要求：
- 应收账款回款情况
- 资金计划执行情况
- 核心费用专项明细
- 合同/在手订单
- 项目进度
- 全年预测
- 责任人和完成时点

## 输出规则

- 可自动生成的章节必须尽量完整，不得以“数据缺失”为由省略核心经营表。
- 必须人工补充的内容不得编造；统一放在结尾“数据限制与待补说明”。
- 如果系统已有部分费用指标，应作为“系统可取费用指标参考”正常分析，不能因为专项明细缺失而省略。
- 自动可取的成本费用指标不得写成 `【待补】`。
