# 真实经营分析报告风格参考

仅作语言风格参考，不覆盖 `report-generation.md` 的流程和硬约束。

## 风格
- 结论先行。
- 先说对象，再说指标，再说差异，再说经营含义。
- 每个核心章节至少有一组数字或一张表，并有 2-5 条业务判断。
- 黄色 / 红色风险必须点名对象、证据和后续动作。

## 避免
- 宣传腔、咨询腔、AI 腔。
- “整体良好 / 需关注”这类空泛判断。
- 大面积 `【人工补充】` 占位表。

## 可复用句式
- “从累计完成看，A 单元营收完成率为 X%，低于目标 Y 个百分点，缺口集中在 B / C。”
- “收入端完成进度尚可，但税前利润完成率低于收入完成率，说明利润转化不足，需关注成本刚性和项目毛利。”
- “应收、资金计划和专项核心费用当前未接入系统，本报告仅在结尾列示补数要求，待业务侧补齐后复核。”
