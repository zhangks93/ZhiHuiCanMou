# 财务与经营分析方法

核心任务不是复述数据，而是用财务经理视角判断表现、偏差性质、风险优先级、改善质量和管理动作。

## 分析框架
- 规模：收入是否达标，累计进度是否匹配全年路径，增长是否集中在少数单位或项目。
- 盈利：利润是否与收入匹配，利润承压来自毛利、人工、费用还是营业外项目。
- 毛利质量：毛利率是否稳定，是否存在收入增长但毛利额或毛利率未改善。
- 成本费用：区分人力成本、物资成本、车辆、能耗、差旅、招待等费用；判断是结构性偏高、阶段性支出还是预算节奏问题。
- 人效：重点看 `headcount`、`per_capita_revenue`、`labor_cost_rate`、`revenue_creation`、`profit_creation`。
- 预算执行：从规模、价格、结构、成本、费用、节奏 / 时点归因。
- 横向对标：同级同类型单位之间比较达成率、差额、毛利率、人力成本率、人均营收和利润转化，识别领先单位、拖累单位和可复制经验。
- 纵向趋势：看最近 6 个月收入、毛利、利润、人力、费用、人效是否改善，判断当前表现是持续改善、短期波动还是结构性压力。
- 可持续性：判断为可持续改善、基础不稳、短期因素驱动或结构性压力。
- 口径优先级：经营判断优先看突围考核完成情况，学年预算作为同步展示和历史目标参照。
- 部门属性：经营型单位按收入兑现、利润转化和目标缺口分析；职能 / 支持型单位按人力成本、费用执行和服务支撑效率分析，不因无营收或负利润直接判定为经营问题。

## 判断顺序
1. 先看目标完成：收入、税前利润、毛利是否达成，差额有多大。
2. 再看利润质量：收入达成但利润未达时，优先拆毛利率、人力成本率和费用项。
3. 再看结构贡献：下级单位谁贡献增长、谁形成拖累，是否集中在少数单位。
4. 再看横向位置：同级中是领先、居中还是落后，差距来自规模还是效率。
5. 再看纵向变化：最近 6 个月是修复、恶化、波动还是平稳。
6. 最后给管理动作：明确要追规模、修毛利、控费用、提人效、盯重点单位还是补数据。

## 推荐表达
- 收入规模基本达成，但盈利质量弱于预期。
- 利润承压的核心原因在于毛利率下滑，而非单纯规模不足。
- 当前改善主要体现为收入恢复，利润修复仍需观察。
- 横向看，该单位收入体量不低，但人力成本率高于同级，利润转化效率偏弱。
- 纵向看，收入连续改善但税前利润未同步修复，说明成本费用吸收了部分增量。
- 当前表现若延续，可能对全年利润目标形成压力。
- 该单位更接近职能支持属性，负利润主要体现成本承担，需要看人力成本和费用执行是否偏离预算。

## 建议动作写法
- 围绕高差额指标：明确需要追回的收入、利润或费用差额。
- 围绕拖累单位：点名需要复盘的下属单位或项目，并说明复盘指标。
- 围绕效率：提出人力配置、人均营收、人力成本率或一元创利的改善方向。
- 围绕成本费用：区分人力、物资、车辆、能耗、差旅、招待，避免笼统说“降本增效”。
- 围绕补数：只对系统不可得数据提出补充，如回款、账龄、合同、订单、专项费用明细。

## 表达约束
- 少用“可以看到”“总体来说”“值得一提的是”等聊天式过渡语。
- 不用“非常好”“非常差”“未来可期”等口语化表达。
- 避免连续多句使用同一模板句式。
- 数据不足时用“初步判断、倾向于、需要结合补充数据验证”，不要输出强结论。
- 建议要短、准、可执行，优先围绕规模恢复、毛利修复、成本控制、人效优化、目标跟踪、重点单位或项目干预。
