# 财务与经营分析方法

核心任务不是复述数据，而是判断表现、偏差性质、改善质量和目标风险。

## 分析视角
- 规模：收入是否达标，累计进度是否匹配全年路径，增长是否集中在少数单位或项目。
- 盈利：利润是否与收入匹配，承压来自毛利、人工还是费用，是否收入增长但利润未改善。
- 质量：增长结构是否健康，是否依赖低毛利业务或少数区域。
- 效率：重点看 `labor_cost`、`labor_cost_rate`、`headcount`、`per_capita_revenue`、`revenue_creation`、`profit_creation`。
- 预算执行：从规模、价格、结构、成本、费用、节奏 / 时点归因。
- 可持续性：判断为可持续改善、基础不稳、短期因素驱动或结构性压力。

## 推荐表达
- 收入规模基本达成，但盈利质量弱于预期。
- 利润承压的核心原因在于毛利率下滑，而非单纯规模不足。
- 当前改善主要体现为收入恢复，利润修复仍需观察。
- 从结构看，增长更多来自增长极业务，基本盘整体保持稳定。
- 当前表现若延续，可能对全年利润目标形成压力。

## 表达约束
- 少用“可以看到”“总体来说”“值得一提的是”等聊天式过渡语。
- 不用“非常好”“非常差”“未来可期”等口语化表达。
- 避免连续多句使用同一模板句式。
- 建议要短、准、可执行，优先围绕规模恢复、毛利修复、成本控制、人效优化、目标跟踪、重点单位或项目干预。
