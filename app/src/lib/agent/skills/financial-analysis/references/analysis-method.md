# 财务与经营分析方法

## 核心立场
你不是单纯回答“发生了什么”，而是要说明：
- 当前表现是好还是弱
- 偏差是结构性的还是阶段性的
- 改善是否可持续
- 当前状态是否会影响全年目标

## 必须优先使用的分析视角

### 1. 规模视角
重点检查：
- 收入是否达到预期
- 累计进度是否匹配全年路径
- 增长是否广泛，还是只集中在少数节点

### 2. 盈利视角
重点检查：
- 利润是否与收入表现匹配
- 利润承压是由毛利、人工还是费用造成
- 是否存在“收入增长但利润未改善”

### 3. 质量视角
重点检查：
- 增长是否建立在健康的业务结构上
- 是否低毛利业务占比在上升
- 是否过度依赖少数区域、节点或业务线

### 4. 效率视角
重点关注：
- labor_cost
- labor_cost_rate
- headcount
- per_capita_revenue
- revenue_creation
- profit_creation

### 5. 预算执行视角
做预算偏差分析时，优先从以下维度归因：
- 规模
- 价格
- 结构
- 成本
- 费用
- 节奏 / 时点

### 6. 可持续性视角
要明确判断当前表现属于：
- 可持续改善
- 有改善但基础不稳
- 主要依赖短期因素
- 存在结构性压力

## 推荐判断句式
优先使用这类表达方式：
- 收入规模基本达成，但盈利质量弱于预期。
- 利润承压的核心原因在于毛利率下滑，而非单纯规模不足。
- 当前经营改善主要体现为收入恢复，利润修复仍需观察。
- 从结构看，增长更多来自增长极业务，基本盘整体保持稳定。
- 从效率看，人效改善有限，成本费用仍有优化空间。
- 当前表现若延续，可能对全年利润目标形成压力。

## 建议输出方式
建议尽量短、准、可执行。

建议方向可优先分为：
- 规模恢复
- 毛利修复
- 成本控制
- 人效优化
- 目标跟踪
- 重点节点干预
