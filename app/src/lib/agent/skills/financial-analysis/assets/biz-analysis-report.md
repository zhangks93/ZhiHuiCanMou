## 写作规范

- **数值单位**：金额用万元（保留1位小数），比率用%（保留1位小数），人数用人
- **完成率判断**：
  - ≥ 90%：✅ 达标
  - 80–90%：⚠️ 待关注
  - < 80%：🔴 预警
- **同比口径**：yoy_value 正值=增长，负值=下降，用"同比增长X%"或"同比下降X%"表述
- **表格格式**：多节点对比一律用 Markdown 表格，单节点分析可用列表
- **语言风格**：简洁、客观、有结论；避免堆砌数字，重点突出异常和趋势；可参考麦肯锡专业咨询的风格
- **报告长度**：完整报告约5000-10000字，根据分析结果酌情考虑
