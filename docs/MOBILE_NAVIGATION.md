# 移动端导航优化

## 概述
针对移动端用户体验进行了全面优化，采用底部导航栏设计，符合移动端操作习惯。

## 主要改动

### 1. Header（顶部栏）
- **移动端**：仅显示 logo，无任何操作元素（避免被手机顶端栏遮挡）
- **桌面端**：保持原有布局（菜单按钮、日期、通知、用户头像）

### 2. BottomNav（底部导航栏）
新增移动端专用底部导航组件，包含：

#### 主导航区（4个主要功能）
- 显示前4个最常用的导航项
- 每个导航项包含图标和文字标签
- 激活状态有视觉反馈（颜色加深、字体加粗）
- 支持角标提示（badge）

#### 更多菜单
- 点击"更多"按钮弹出全屏菜单
- 包含用户信息卡片（头像、姓名、日期）
- 通知按钮（带未读提示）
- 其余所有导航项（超过前4个的功能）
- 退出登录按钮

### 3. MainLayout（主布局）
- 移动端：底部增加 80px padding（为底部导航栏留出空间）
- 桌面端：保持原有 32px padding
- 响应式适配，平滑过渡

### 4. 动画效果
- 更多菜单：从底部滑入动画（animate-slide-up）
- 遮罩层：淡入动画（animate-fade-in）
- 导航项：点击缩放反馈（active:scale-95）

## 技术实现

### 文件结构
```
app/src/components/Layout/
├── BottomNav.tsx       # 新增：移动端底部导航
├── Header.tsx          # 修改：移动端简化
├── MainLayout.tsx      # 修改：引入 BottomNav
└── Sidebar.tsx         # 保持不变（桌面端使用）
```

### 响应式断点
- 移动端：`< 1024px` (lg breakpoint)
- 桌面端：`>= 1024px`

### 安全区域支持
- 使用 `env(safe-area-inset-bottom)` 适配有刘海/底部手势条的设备
- 自动添加底部安全区域 padding

## 用户体验优化

### 移动端特性
1. **单手操作友好**：所有主要功能在底部，拇指可轻松触达
2. **视觉清晰**：顶部无干扰，内容区域最大化
3. **操作直观**：符合移动端用户习惯（类似微信、支付宝等主流 App）
4. **反馈及时**：点击有视觉反馈，状态变化明显

### 桌面端保持
- 侧边栏导航（可折叠）
- 顶部完整功能栏
- 更大的内容展示区域

## 测试建议

### 移动端测试
1. 使用 Chrome DevTools 移动设备模拟器
2. 测试不同屏幕尺寸（iPhone SE, iPhone 14, iPad）
3. 验证底部导航栏是否正确显示
4. 测试"更多"菜单的展开/收起
5. 验证安全区域适配（iPhone X 及以上）

### 桌面端测试
1. 验证原有布局未受影响
2. 测试侧边栏折叠/展开
3. 验证响应式断点切换

## 后续优化方向

1. **手势支持**：添加左右滑动切换页面
2. **底部导航定制**：允许用户自定义显示的4个主要功能
3. **深色模式**：适配移动端深色模式
4. **性能优化**：懒加载更多菜单内容
5. **无障碍**：增强屏幕阅读器支持
