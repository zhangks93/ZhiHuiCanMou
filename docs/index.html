核心能力

围绕经营管理闭环组织信息

当前应用不是单一报表页，而是面向管理者日常工作的工作台：先聚合事实，再辅助判断，最后回到行动。

01

工作台总览

默认展示今日经营简报、今日日程、协作提醒、Top 商机与 AI 快捷问题。

02

数据中枢

经营、商机、出差、考勤、人员、规划以统一入口组织，支持按模块切换。

03

智能体分析

技能化 Agent 可调用组织解析、经营查询、月度规划和文件读取工具。

04

多端交付

同一套前端可构建 Web、Windows/macOS/Linux 桌面端与 Android APK。

交付与安全

前端、桌面、移动与公开页面各自有清晰发布链路

仓库内置 CI、GitHub Pages 构建、Tauri Release 构建和公开产物安全扫描，降低私有数据误发布风险。

Web / Pages

React 应用构建到 app/dist；产品页从 docs 生成 .pages-artifact 后发布到 GitHub Pages。

桌面 / Android

Tauri 2 负责桌面端与 Android APK 打包，Deep Link scheme 为 canmou。

数据边界

private-data、docs/data 和 Excel 文件不会进入公开产物；CI 会检查 RLS、密钥和私有数据。
