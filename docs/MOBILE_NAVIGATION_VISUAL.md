## 交互效果

### 底部导航栏
- **未激活状态**：灰色图标 + 文字
- **激活状态**：青绿色图标 + 加粗文字
- **点击反馈**：轻微缩放动画（scale-95）
- **角标提示**：红点显示未读/待办

### 更多菜单
- **打开动画**：从底部滑入（300ms）
- **背景遮罩**：半透明黑色，点击关闭
- **菜单面板**：白色背景，最大高度 70vh，可滚动
- **关闭方式**：
  1. 点击遮罩
  2. 点击右上角 X 按钮
  3. 点击任意导航项（自动跳转并关闭）

### 用户信息卡片
- 显示头像（圆形）
- 显示姓名
- 显示当前日期
- 浅色背景区分

### 导航项样式
- **未激活**：灰色文字，hover 浅灰背景
- **激活**：青绿色文字，左侧青绿色边框，浅青绿背景
- **角标**：右侧显示数字或标签

## 响应式行为

### 移动端（< 1024px）
- 显示底部导航栏
- 隐藏侧边栏
- Header 仅显示 logo
- 主内容区底部留出 80px 空间

### 桌面端（>= 1024px）
- 隐藏底部导航栏
- 显示侧边栏（可折叠）
- Header 显示完整功能
- 主内容区正常布局

## 颜色方案

- **主色调**：深邃墨蓝 (#1a2744)
- **强调色**：青绿 (#0d9488)
- **背景色**：白色 (#ffffff)
- **文字色**：深灰 (#2d3748)
- **次要文字**：中灰 (#64748b)
- **边框色**：浅灰 (#e8e6e3)

## 安全区域适配

支持 iPhone X 及以上设备的安全区域：
- 自动检测 `safe-area-inset-bottom`
- 底部导航栏自动增加底部 padding
- 确保内容不被手势条遮挡
