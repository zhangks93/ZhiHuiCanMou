# 底部导航栏布局优化

## 优化内容

### 1. 调整底部导航栏顺序
**新布局（从左到右）：**
```
┌─────────────────────────────────────────┐
│  [分析]  [日程]  [总览]  [经营]  [更多]  │
└─────────────────────────────────────────┘
```

**具体调整：**
- **位置 1**：智能分析（原首页总览的位置）
- **位置 2**：日程提醒
- **位置 3**：首页总览（中间位置，代替常用数据）
- **位置 4**：经营数据

**设计理念：**
- 将"总览"放在中间位置，作为核心入口，符合移动端习惯
- "智能分析"作为重要功能提升到第一位
- 保留"日程"和"经营"作为常用功能

### 2. 移动端名称统一为两个字

所有导航项在移动端显示时自动缩短为两个字，提升视觉简洁度和可读性。

**名称映射表：**

| 原名称 | 移动端名称 |
|--------|-----------|
| 首页总览 | 总览 |
| 日程提醒 | 日程 |
| 常用数据 | 数据 |
| 经营数据 | 经营 |
| 商机管理 | 商机 |
| 竞对档案 | 竞对 |
| 出差管理 | 出差 |
| 考勤管理 | 考勤 |
| 系统链接 | 链接 |
| 智能分析 | 分析 |
| 项目协同 | 协同 |

**实现方式：**
```typescript
const getMobileLabel = (label: string): string => {
  const mobileLabels: Record<string, string> = {
    '首页总览': '总览',
    '日程提醒': '日程',
    // ... 其他映射
  }
  return mobileLabels[label] || label.slice(0, 2)
}
```

### 3. 更多菜单内容调整

**更多菜单现在包含：**
- 常用数据（从底部导航移除）
- 商机管理
- 竞对档案
- 出差管理
- 考勤管理
- 系统链接
- 其他启用的模块

## 优化优势

### 1. 视觉简洁
- 两个字的名称更加简洁，减少视觉负担
- 图标 + 两字文字的组合更加平衡美观

### 2. 操作便捷
- "总览"放在中间，拇指最容易触达
- 高频功能（分析、日程、经营）都在底部，无需进入更多菜单

### 3. 信息层级清晰
- 核心功能在底部导航栏
- 次要功能在更多菜单
- 用户可快速找到所需功能

### 4. 符合移动端习惯
- 中间位置放置主要入口（类似微信的"微信"按钮）
- 两字命名符合中文移动应用习惯
- 底部导航栏高度和间距适合单手操作

## 技术实现

### 自定义布局逻辑
```typescript
const getBottomNavItems = () => {
  const homeItem = allNavItems.find(item => item.to === '/')
  const aiItem = allNavItems.find(item => item.to === '/ai')
  const scheduleItem = allNavItems.find(item => item.to === '/schedule')
  const bizDataItem = allNavItems.find(item => item.to === '/biz-data')

  const bottomNavItems = []
  if (aiItem) bottomNavItems.push(aiItem)
  if (scheduleItem) bottomNavItems.push(scheduleItem)
  if (homeItem) bottomNavItems.push(homeItem)
  if (bizDataItem) bottomNavItems.push(bizDataItem)

  return bottomNavItems
}
```

### 动态过滤更多菜单
```typescript
const primaryNavPaths = new Set(primaryNavItems.map(item => item.to))
const moreNavItems = allNavItems.filter(item => !primaryNavPaths.has(item.to))
```

## 兼容性说明

- **桌面端**：不受影响，继续使用完整名称和侧边栏布局
- **移动端**：自动应用两字名称和底部导航栏
- **响应式**：在 1024px 断点自动切换
