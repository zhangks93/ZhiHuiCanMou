# 主管 / 经理：查看下属汇总

## 下属汇报查看

1. 进入 **工作汇报** 页面
2. 切换至「下属汇总」标签
3. 按模块、汇报人、周期浏览下属的工作进展

## 智能分析

1. 进入 **智能分析** 页面（侧边栏「智能分析」）

### 下属工作进展 AI 汇总

系统将下属多人在各模块的汇报进行 AI 汇总，生成结构化摘要。点击「刷新」可重新生成。

### 对汇报内容追问

在输入框输入问题，例如：
- 北区商机推进情况如何？
- 本周有哪些重要进展？
- 谁在跟进广东高校项目？

AI 将基于汇报上下文回答。

### 经营 × 商机智能匹配分析

展示经营数据与商机的智能洞察，包括优势业务、缺口预警、转化建议等。
