# 员工：如何汇报工作

## 汇报入口

1. 进入 **工作汇报** 页面（侧边栏「工作汇报」）
2. 切换至「我的汇报」标签
3. 点击「新增汇报」

## 填写内容

### 关联模块

选择本次进展所属模块，例如：日程提醒、商机管理、出差管理等。

### 进展说明

简要描述工作进展，例如：
- 本周完成 XX 项目需求评审
- 北区某高校商机进入拟标阶段

### 飞书链接（可选）

若有详细文档或表格，可附加链接：
1. 在「飞书文档/表格链接」输入框粘贴链接（如 `https://xxx.feishu.cn/docx/...`）
2. 可为链接填写标题便于识别
3. 点击「添加」加入列表，支持多条链接

### 提交

点击「提交」后，汇报将出现在「我的汇报」列表，并可被上级在「下属汇总」及「智能分析」中查看。
