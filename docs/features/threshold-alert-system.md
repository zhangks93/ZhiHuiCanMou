# 经营数据预警阈值系统

## 功能概述

在经营数据页面的表格和图表中，根据完成率自动显示预警颜色，帮助用户快速识别需要关注的业务单元。

## 功能特性

### 1. 可配置的预警阈值

在设置页面可以配置两类业务的预警阈值：

- **默认阈值**：适用于后勤集团、三中心、三区域等业务单元
  - 黄色预警：完成率 < 80%
  - 红色预警：完成率 < 70%

- **食堂阈值**：适用于自有学校食堂业务单元
  - 黄色预警：完成率 < 80%
  - 红色预警：完成率 < 72%

### 2. 智能业务分类

系统会根据业务单元名称自动判断应用哪套阈值：
- 包含"食堂"、"餐饮"、"伙食"关键词的单元使用食堂阈值
- 其他单元使用默认阈值

### 3. 视觉预警设计

#### 表格视图
完成率单元格显示为带颜色的标签：
- **绿色**（正常）：完成率 ≥ 黄色预警阈值
- **黄色**（警告）：红色预警阈值 ≤ 完成率 < 黄色预警阈值
- **红色**（危险）：完成率 < 红色预警阈值

标签样式：
- 圆角边框
- 半透明背景色
- 对应颜色的边框
- 清晰的数值显示

#### 图表视图
柱状图的"实际"数据柱会根据完成率显示不同颜色：
- **绿色**：正常完成
- **黄色**：需要关注
- **红色**：严重预警

### 4. 实时更新

在设置页面修改阈值后，经营数据页面会立即响应更新，无需刷新页面。

## 使用方法

### 配置阈值

1. 进入"设置"页面
2. 找到"经营数据预警阈值"卡片
3. 点击"编辑"按钮
4. 调整黄色预警和红色预警的百分比值
5. 点击"保存"按钮

注意：黄色预警阈值必须大于红色预警阈值

### 查看预警

1. 进入"经营数据"页面
2. 在表格视图中，完成率列会显示带颜色的标签
3. 在图表视图中，柱状图会根据完成率显示不同颜色
4. 快速识别需要关注的业务单元

## 技术实现

### 核心文件

- `app/src/lib/thresholdConfig.ts` - 阈值配置管理
- `app/src/pages/Settings.tsx` - 设置页面（阈值编辑）
- `app/src/components/BizData/TableView.tsx` - 表格视图（预警显示）
- `app/src/components/BizData/ChartView.tsx` - 图表视图（预警显示）

### 数据存储

阈值配置存储在浏览器的 localStorage 中，键名为 `biz_data_threshold_settings`。

### 事件通信

使用 `window.dispatchEvent` 和 `window.addEventListener` 实现跨组件通信：
- 事件名：`threshold-updated`
- 触发时机：设置页面保存阈值后
- 监听组件：TableView、ChartView

## 设计理念

### 用户友好的视觉设计

1. **色彩系统**
   - 使用语义化的颜色：绿色（安全）、黄色（警告）、红色（危险）
   - 半透明背景避免视觉疲劳
   - 清晰的边框增强识别度

2. **信息层级**
   - 预警信息通过颜色快速传达
   - 数值保持清晰可读
   - 不干扰其他数据的展示

3. **交互体验**
   - 阈值可编辑，满足不同业务需求
   - 实时更新，无需刷新页面
   - 一键恢复默认值
